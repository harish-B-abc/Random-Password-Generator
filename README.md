# Random Password Generator

A simple Python program that generates random and secure passwords based on the length specified by the user.

## Features

- Generate passwords of any length
- Includes uppercase letters
- Includes lowercase letters
- Includes numbers
- Includes special characters
- Simple and beginner-friendly Python project

## Technologies Used

- Python
- `random` module
- `string` module
